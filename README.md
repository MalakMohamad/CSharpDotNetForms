# C# .NET Forms Practice

A collection of hands-on C# and .NET desktop application exercises built with **Avalonia UI** and **XAML**. This repository documents my learning journey as I strengthen my programming fundamentals and practice building interactive user interfaces.

## Projects

### 1. Form2Practice1 — Payment Method Form
A simple payment selection application that demonstrates radio buttons, conditional logic, and event handling.

**Features**
- Select a payment method: Credit Card, Cash, or Bank Transfer.
- Display a message based on the selected payment method.
- Clear selections and reset the output.
- Customize the appearance of buttons and the interface.

### 2. Form2Practicing2 — Shopping Cart with Discounts
A shopping cart application that calculates the total price of selected products and applies a student discount.

**Features**
- Select products using checkboxes: Laptop, Mouse, and Keyboard.
- Apply a 10% student discount or choose no discount.
- Calculate and display the final price.
- Clear product selections and reset the form.

### 3. Form2Practicing4 — Restaurant Order Form
A restaurant ordering application that calculates a bill based on selected food, drinks, and order type.

**Features**
- Select food items: Burger, Pizza, and Pasta.
- Select drinks: Water, Juice, and Coffee.
- Choose between Dine-in and Takeaway.
- Add a 5 SAR packaging fee for takeaway orders.
- Calculate the order total and reset the form.

## Technologies Used

- **C#** — Application logic and event handling
- **.NET** — Application development platform
- **Avalonia UI** — Cross-platform desktop user interfaces
- **XAML** — Interface layout and styling
- **JetBrains Rider** — Development environment

## Concepts Practiced

- Variables, data types, and arithmetic operations
- Conditional statements (`if`, `else if`, `else`)
- Checkboxes and radio buttons
- Button click events and event handlers
- Accessing UI controls by name
- Updating `TextBlock` content dynamically
- Resetting UI control states
- Layouts using `StackPanel`, `Grid`, and `GroupBox`
- Styling controls and customizing button hover effects

## Getting Started

### Prerequisites
- .NET SDK
- JetBrains Rider or another compatible .NET development environment

### Run a Project
1. Clone or download this repository.
2. Open the desired project's `.csproj` file or solution in Rider.
3. Restore the required NuGet packages.
4. Build and run the application.

This repository serves as a practical workspace for improving my C# programming skills through small desktop applications. Each project builds on previously learned concepts while introducing new UI controls, event-driven programming techniques, and application logic.
