# Form2Practicing2 — Shopping Cart with Discounts

A C# desktop application built with **.NET and Avalonia UI** to practice interactive UI development, conditional logic, and basic shopping cart calculations.

## Features

- **Product Selection:** Select a laptop, mouse, and keyboard using checkboxes.
- **Student Discount:** Apply a 10% discount to the total price.
- **No Discount Option:** Calculate the total without a discount.
- **Calculate Total:** Display the final price based on selected products and discount status.
- **Clear Button:** Reset all product selections, discount options, and the result message.
- **Custom UI Design:** Uses a pink background, beige product selection panel, and styled buttons.

## How to Run

1. Install the .NET SDK and JetBrains Rider.
2. Clone or download this repository.
3. Open the solution or `.csproj` file in Rider.
4. Restore the required NuGet packages.
5. Run the application.
