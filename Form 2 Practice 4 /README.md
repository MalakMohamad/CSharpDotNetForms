# Form2Practicing4 — Restaurant Order Form

A C# desktop application built with **.NET and Avalonia UI** to practice interactive form development, user input handling, conditional statements, and price calculations.

## Features

- **Food Selection:** Choose from Burger, Pizza, and Pasta using checkboxes.
- **Drink Selection:** Choose from Water, Juice, and Coffee.
- **Order Type:** Select Dine-in or Takeaway using radio buttons.
- **Order Calculation:** Calculate the total price based on selected food and drinks.
- **Takeaway Fee:** Add a 5 SAR packaging fee to takeaway orders.
- **Place Order:** Display the calculated bill based on the selected order type.
- **Clear Order:** Reset all selections and restore the default message.
- **Custom UI Styling:** Uses an Alice Blue background, grouped menu sections, and styled buttons.

## How to Run

1. Install the .NET SDK and JetBrains Rider.
2. Clone or download the repository.
3. Open the solution or `.csproj` file in Rider.
4. Restore the required NuGet packages.
5. Run the application.
