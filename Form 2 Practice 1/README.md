# Form2 Practicing 1

A beginner C# desktop application built with **.NET and Avalonia UI** to practice GUI development, event handling, and user interaction.

## Features

- **Payment Method Selection:** Choose between Credit Card, Cash, and Bank Transfer using radio buttons.
- **Pay Button:** Displays a message based on the selected payment method.
- **Welcome Button:** Displays a welcome message.
- **Clear Button:** Resets the displayed message and clears the selected payment method.
- **Custom UI Styling:** Uses a Wheat background, Brown buttons, rounded corners, and customized button hover styles.

## Technologies Used

- C#
- .NET
- Avalonia UI
- XAML

## Concepts Practiced

- Event handling with button click events
- Radio buttons and selection states
- Accessing UI controls using `x:Name` / `Name`
- Conditional statements (`if`)
- Updating `TextBlock` content dynamically
- Clearing and resetting UI controls
- Styling UI components with XAML

## How to Run

1. Install the .NET SDK and JetBrains Rider.
2. Clone or download this repository.
3. Open the solution or `.csproj` file in Rider.
4. Restore the NuGet packages if prompted.
5. Run the application.
